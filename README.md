# PerfEngineerAI

**AI performance engineer for backend systems.**

Give it a performance goal. It finds the system limit, investigates the bottleneck, and verifies the diagnosis with experiments.

## Status

🚧 Early experimental development.

The first focus is performance investigation of Java / Spring Boot services under load.

## Goals

- Find sustainable throughput under a defined SLO
- Identify likely system bottlenecks
- Verify hypotheses with controlled performance experiments
- Produce concise, evidence-based performance reports
